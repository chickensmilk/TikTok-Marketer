# IPM To-Do Assignment & Timeline Workflow

## To-Do Naming Convention
`[STATUS INDICATOR - HDD: m/d] - Month Xth - Topic - Educational/Targeted ➡️ (PDD: m/d - HDD: m/d)`

Example: `[CREATE PROMPT & DRAFT COPY] - May 19th - Refer a Friend – Spread the Word - Educational ➡️ (Prompt HDD: m/d, Outline HDD: m/d)`

---

## 6-Step Workflow (Status Indicators)

1. **[CREATE PROMPT & DRAFT COPY] ➡️**
   - Strategist creates the prompt and drafts copy
   - When ready: update indicator, add new HDD for design phase, assign to **designer**

2. **[DESIGN HEADER] ➡️**
   - **Designer** creates header image and any other design assets based on prompt
   - When ready: update indicator, add new HDD for outline phase, assign back to **strategist**

3. **[CREATE OUTLINE FOR AM] ➡️**
   - **Strategist** finalizes email + social/SMS copy, builds in platform, drafts AM outline
   - When ready: update indicator, assign to **Account Coordinator(s)**

4. **[REVIEW] ➡️**
   - Account Coordinator reviews for QA
   - If edits needed → back to **Strategist**, update to `[EDIT] ➡️`
   - If approved → draft for client, update to `[PENDING CLIENT] ➡️`

5. **[APPROVED] ➡️**
   - Client approves → assign back to **Strategist** (include screenshot of approval)
   - Strategist moves to-do to send date
   - If platform allows scheduling → update to `[SCHEDULED] ➡️`

6. **[SENT] ➡️**
   - Strategist sends email + social/SMS on projected send date
   - Upload send confirmation screenshots, assign to **Account Manager** for final confirmation

## Designer's Role in IPM

The designer is only involved at **Step 2 (DESIGN HEADER)**. When a Basecamp IPM task lands in a designer's queue, it will be labeled `[DESIGN HEADER - HDD: m/d]`. The designer:
- Creates the header image + any needed design assets
- Marks complete and reassigns to the strategist when done

**Header design can be assigned to Dexter, Lezly, Gaby, or RJ — choose based on current workload capacity. Do not default to one designer.**

1. **Summary table** — deliver first, before any notes or comments

- Always include Client column

## Date Calculation Formulas

The **Projected Send Date** is always stated in the to-do title (e.g., "May 12th"). Work backwards from that date to set all timeline milestones.

**Never land a PDD or HDD on a weekend or DR-observed holiday.** If a calculated date falls on one, move it to the next business day. See DR holiday list in SKILL.md.

### Melany Client Timeline (Full Track)

Work backwards from the Projected Send Date:

```
Projected Send Date  (from task title)
  ↑
Outline HDD:         1–4 weeks before send date
                     → Use 2 weeks before if there's ample lead time
                     → Use 1 week before if assigned close to the send date or team member capacities are tight

Outline PDD:         ~ 3-4 weeks before send date (same week as HDD or 1 week earlier)
                     → When timeline allows, PDD = 4 weeks out, HDD = 2 week out

Header Design HDD:   2–3 days before the Outline PDD
Header Design start: Same day or day after Create Prompt window ends

Create Prompt:       Spans 2–7 days
                     Starts ~3–4 weeks before send date
```

**Example — Send Date: May 12**
```
1. Create Prompt & Draft Copy:   4/16 – 4/20
2. Header Design Due Between:    4/21 – 4/23
3. Outline PDD:                  4/27  (~2 weeks before 5/12)
4. Outline HDD:                  5/7   (~1 week before 5/12; pushed from 5/5 — reporting week)
5. Projected Send Date:          5/12
```

**Example — Send Date: April 13**
```
1. Create Prompt & Draft Copy:   3/23 – 3/25
2. Header Design Due Between:    3/26 – 3/27
3. Outline PDD:                  3/30
4. Outline HDD:                  4/6
5. Projected Send Date:          4/13
```

### Lezly Client Timeline (Simplified Track)

Work backwards from the Projected Send Date:

```
Projected Send Date  (from task title)
  ↑
Outline HDD:         1–4 weeks before send date
                     → Use 2 weeks before if there's ample lead time
                     → Use 1 week before (minimum) if assigned late

Outline PDD:         ~ 3-4 weeks before send date (same week as HDD or 1 week earlier)
                     → When timeline allows, PDD = 4 weeks out, HDD = 2 week out
                     → Omit PDD if assigned too close to the send date
```

**Example — Send Date: May 19, assigned with good lead time**
```
1. Outline PDD:          4/21   (~4 weeks before 5/19)
2. Outline HDD:          5/5  (~2 weeks before 5/19)
3. Projected Send Date:  5/19
```

**Example — Send Date: March 24, assigned late**
```
1. Outline HDD:          3/17   (1 week before 3/24 — too close to include PDD)
2. Projected Send Date:  3/24
```

> **Tip:** When there's ample lead time, always include both PDD and HDD. The PDD gives the strategist an internal soft deadline; the HDD is what goes in the Basecamp "Due on" field and the status indicator.

### Reporting Week Capacity Constraints

At the start of each month, Melany and Lezly handle IPM reporting tasks (typically month day 1 through second working Monday):

- **Melany:** ~15 hrs tied to reporting; operates at 1/4 to 1/3 normal IPM capacity during this window
  - Max 2 outlines due on the same day when sends fall on Tue/Wed during reporting week
  - Max 3 outlines due on the same day for all other days, if no other projects are due
  - If an Outline HDD lands during reporting week, push it to the nearest Thursday or Friday
- **Lezly:** ~5–7 hrs tied to reporting; factor into her HDDs during this window

## Updating the To-Do Title

When assigning the task, update the title's status indicator:

1. **Remove** the placeholder `[CREATE HDD TIMELINE & ASSIGN]` (or similar) from the title
2. **Set the correct status indicator** for the track, with HDD date(s) filled in

**For Melany clients:**
```
[CREATE PROMPT & DRAFT COPY] - Month Xth - Topic - Educational/Targeted ➡️ (Prompt HDD: m/d, Outline HDD: m/d)
```

**For Lezly clients:**
```
[CREATE OUTLINE FOR AM] Month Xth - Topic - Educational/Targeted ➡️ (PDD: m/d, HDD: m/d)
```

**For Priority tasks (either track), add `‼️` prefix:**
```
‼️ [PRIORITY: STATUS INDICATOR] - Month Xth - Topic - Type ➡️ (Prompt HDD: m/d, Outline HDD: m/d)
```

Always ask if the priorities identified are actually priorities. If they are not, remove the `‼️` prefix

## Quick Reference Checklist — Assigning an IPM To-Do

- [ ] Identify **Projected Send Date** from the task title
- [ ] Determine **Melany vs. Lezly** client track (check client list or who added the task)
- [ ] Calculate **all timeline dates** working backwards from send date — verify no date lands on a weekend or DR holiday
- [ ] **Deliver summary table first** — confirm strategy before writing notes
- [ ] Update **to-do title** with correct status indicator and HDD(s) filled in
- [ ] Set **Assigned to** → Melany S. or Lezly Reyes Norman
- [ ] Set **Due on** → HDD of the current step
- [ ] Set **Estimate** → 2h 30m
- [ ] Set **When done, notify** → per client type (header designer for Melany clients; team per norms for Lezly clients)
- [ ] **After strategy confirmed:** copy Notes + First BC Comment block into the Notes field
- [ ] Flag to Brittney if send date is too close or timeline is unusually tight
