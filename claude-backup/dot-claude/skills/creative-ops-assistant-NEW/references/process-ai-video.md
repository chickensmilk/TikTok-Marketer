# AI Image & Video Creation Process

## Purpose
End-to-end workflow for creating short-form AI videos. Used for quick-turn, simple creative needs.

## When to Use This Process
**Ads team:** When speed is prioritized over polish, concept is simple, no advanced editing required.
**Bring in Creative team when:** Custom design, advanced editing, multiple stakeholders/revisions, brand sensitivity, or high-impact campaigns are involved.

## 7-Step Workflow

1. **Idea Generation / Scripts**
   - If no brief exists, extract: Goal, Audience, Key Message, Tone
   - Use ChatGPT to generate 5–10 video ideas with strong hooks
   - Select 1–2, then refine into a 10–20 second script
   - Output: 1 finalized script → complete BEFORE storyboarding

2. **Storyboarding / Planning**
   - Prompt ChatGPT to generate storyboard from script
   - Must include: Scenes (3–4), Visuals, Camera angle, Action, VO/text

3. **Image Gen**
   - Generate character and asset reference sheets using Higgsfield
   - Use Character Sheet Prompt or Object Sheet Prompt
   - Use Shots to generate multiple variations (up to 4 at once)
   - Select strongest result → use as reference for additional angles and 4-second clips

4. **Video Gen**
   - Use Higgsfield, test same scene across multiple models:
     - Kling 3.0 Omni, Grok Imagine, Sora 2 Max, Google Veo 3.1 Fast
   - Use 4-second clips (most scenes only need 2–3 seconds)
   - Select best result → use that model for remaining scenes

5. **Video Editing**
   - Stitch clips using Adobe Premiere or Canva
   - Arrange in storyboard order, align with voiceover and pacing

6. **Background Music**
   - Download track from Envato

7. **Voice Over**
   - Generate using ElevenLabs
