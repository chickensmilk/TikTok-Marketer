# Headshot Process

## Process
1. HR Team assigns a to-do under "Employee Headshots" to-do list in Basecamp (includes: name, team, manager, start date)
2. **Creative Manager assigns to Multimedia Specialist** — ⚠️ DO NOT change the due date (HR sets it = new hire's start date, when photo is to be taken)
3. Multimedia Specialist schedules time with new hire for in-studio shoot; notifies new hire's department manager
4. Multimedia Specialist sends calendar invite to new hire and their manager
5. After shoot: edit using Lightroom preset (DR standard) + required crop ratios
   - Full Size: 1080×1080px
   - Managers: 375×375px
   - Everyone Else: 70×70px
   - All: .webp export
   - File names must include first and last name
6. Attach final files in QA Multimedia channel and in the to-do; reassign to Creative Team for review
7. Team + Creative Manager assess quality → request revisions or approve
8. Upon approval: Creative Manager reassigns to HR Team + saves to Dropbox

## Assignee
**Always Odette Yermenos** (Multimedia Specialist) — this is never a design task.
**Do not change the due date** — it is set by HR and represents the new hire's start date.
