# Logos & Branding – Process & Policy

## Overview
All logo/branding projects follow a 3-phase process. Revisions do NOT occur within a phase — feedback flows forward to the next phase. Only Phase 3 pauses for final adjustments.

**Prerequisite:** Discovery (client questionnaire + kickoff, research, creative exploration) must be complete before Phase 1 begins. Missing discovery = new scope later.

## Phase 1 — Concept Exploration
**Designer Deliverable:** Up to 15 unique black-and-white digitized logo marks (no color, effects, or mockups).

- Present in a single 3x5 grid to client Google Drive
- Each concept clearly named (e.g., "Concept 01 – Horizon Mark")
- Client selects no more than 3 marks with consolidated feedback
- Feedback from Phase 1 is applied in Phase 2 — Phase 1 does NOT pause for revisions
- Update Basecamp to-do title: Phase → Action → HDD

**If client can't choose:** Recommend a call with AM + designer.

## Phase 2 — Logo Package Development
**Designer Deliverable:** 3 fully distinct logo packages (refined logo + typography + color palette + 1 real-world mockup each).

- Build each as a cohesive system: logo → color → type → mockup
- Client must choose 1 package to move forward — no merging
- Feedback from Phase 2 is applied in Phase 3 — Phase 2 does NOT pause for revisions
- Update Basecamp to-do title: Phase → Action → HDD

## Phase 3 — Finalization & Brand Identity
**Designer Deliverable:** Finalized logo, typography, color palette, imagery, iconography, brand guidelines + up to 3 real-world mockups.
- Logo ONLY package: finalized logo + typography + color palette + 1 mockup
- One final set of minor adjustments before file delivery (this is the only revision pause)
- Export formats: AI, EPS, SVG, PNG (light/dark), JPG in CMYK + RGB + Pantone
- Deliver clean ZIP in client Google Drive: Logos / Typography / Colors / Mockups / Brand Guidelines

## Revision Scope
**In scope:** Proportions, spacing, minor details, color/type changes within chosen direction
**Out of scope:** New logo concepts, merging packages, reopening eliminated options, extra deliverables
