**Two layout modes:**
- Dark (~60%): Navy `#010F37` + grid texture + white text + 3D icons → bold claims, pain points, lead gen
- Light (~40%): White + soft corner blurs + navy text + gray icons → education, social proof, trust

**Universal (every layout):** 4-square color strip [Orange][Blue][Lime][Gray] at top-center. Always.

**Colors:**
- Navy `#010F37` — bg or primary text
- Lime `#D5DE23` — primary CTA, highlight box, badge (appears in EVERY design)
- Blue `#26A9E1` — 3D icons, inline accent, secondary CTA
- Orange `#F6931E` — color strip, small accent dots only (1–2 per layout), gradient endpoint
- Gray strip `#808285` — 4th square in color watermark

**Buttons (priority order):**
1. Lime pill + ↗ = primary CTA
2. Blue pill + ↗ = softer CTA (demos, consultations)
3. Outlined = nav/filter only
4. Circled arrow → = carousel nav only (top-right corner, never a CTA)

**Typography:** Inter Tight only. Pattern: line 1 regular/light → line 2 extrabold (setup + punchline rhythm)

**Lime highlight box:** 1 per layout max. Most important word/phrase. Used in ~60% of designs.

**Lime circle badge:** Circular badge with icon + curved text. Meta-commentary aside. Bottom corner. ~30% of designs.

**Orange dot:** Always small, decorative, 1–2 per layout. Never large fill.

**Gradient:** Blue → Lime → Orange (strict order). Used on tubes (light mode) and inline text.

**Dark mode only:** Grid texture, 3D glass icons, frosted glass cards
**Light mode only:** Soft corner blurs, vibrant gradient tubes, gray outlined icons, gray dot grid

**Why:** Extracted from 25 real DR ads across multiple formats.
**How to apply:** Reference when building or reviewing any DR digital product.
