Richard has an idea for a web or desktop app for Basecamp todo triage:

- User sets hierarchy/priority rules (like Shay → Nate → Managers → oldest)
- App walks through todos one at a time based on those rules
- "Next" button advances to the next todo
- "Skip" button skips a todo
- Settings are configurable by the user or anyone using the tool

**Why:** To automate the prioritization logic currently being done manually in this BC assistant workflow.

**How to apply:** No action items yet — just keep in mind as a potential build when Richard brings it up. Could be an extension of the current Basecamp assistant work.
