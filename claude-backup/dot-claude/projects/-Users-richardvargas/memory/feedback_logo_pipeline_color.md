When presenting logo color explorations in the pipeline, single-color fills on the entire mark are not acceptable. The designer expects:

- **Color hierarchy**: which element (mark, wordmark, rule, accent) gets which color and why
- **Color theory**: contrast relationships, warm/neutral pairings, how elements interact
- **Strategic role-assignment**: primary brand color for the hero element, charcoal/neutral for supporting type, accent color for rule or separator elements

**Why:** A logo in practice has two or more color roles. Dumping one color on the whole mark looks like a mockup shortcut, not a real color application. The designer caught this immediately.

**How to apply:** Before generating color logo variants, present the color role strategy as a decision (e.g., "Monogram in forest green + wordmark in charcoal" vs. "Monogram in charcoal + wordmark in forest green" vs. "O in charcoal, C in green within the monogram"). Let the designer approve the strategy first, then generate.
