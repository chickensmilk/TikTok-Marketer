Use this format when drafting first comments for creative task assignments in Basecamp:

```
Hey @First.Last!

[Brief context sentence if needed]

[Numbered list of items/pages if applicable:]
1. Item one
2. Item two
3. Item three

PDD: m/d
HDD: m/d
EST: Xhrs (or range like 6-7hrs)
REVs: Xhrs (or range like 3-4hrs)
Backup: [Name]
```

**Why:** Richard applies colored highlighting to PDD/HDD/EST/REVs in Basecamp's rich text editor after posting — the CLI posts plain text, and he edits the formatting himself.

**How to apply:**
- Always use numbered lists when listing pages, templates, or items (not bullet points)
- PDD/HDD/EST/REVs each on their own line, no bullets
- Use `@First.Last` for @mentions — Basecamp resolves these correctly
- Do NOT add extra notes or context beyond what Richard provides — post his text as-is
