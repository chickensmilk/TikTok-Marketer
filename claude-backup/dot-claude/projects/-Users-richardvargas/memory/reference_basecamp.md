## Team Time-Tracking Convention

Basecamp BC3 has no native hour logging. DR tracks time estimates via an `EST:` pattern in todo comments (e.g., `HDD: 4/30 EST: 30m- 1hr`). When asked about "hours logged" in Basecamp, look for this pattern in todo comments — there is no dedicated time field.
