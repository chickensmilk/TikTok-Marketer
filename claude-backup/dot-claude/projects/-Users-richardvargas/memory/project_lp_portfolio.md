DR (Digital Resource) manages landing pages for a large portfolio of dental and local service clients.

**Shared domains used:**
- `special-dental-offer.com` — multi-client dental LP host
- `special-local-offer.com` — multi-client local service LP host
- `promo.[client].com` — client-specific promo subdomain
- `services.[client].com` — client-specific services subdomain
- `service.[client].com` — client-specific service subdomain

**URL naming conventions:**
- `-lp` = landing page
- `-ty` = thank you page
- `-lpb` / `-tyb` = B variant (alternate creative)
- `-lpmax` / `-pmax` = Performance Max variant
- `-adgroup-lp` = ad group-specific landing page

**Why:** These are PPC/paid media landing pages built for Google Ads campaigns across multiple dental clients. Naming conventions map to campaign types and A/B variants.

**How to apply:** When Richard references a URL with these suffixes, understand the context (LP = campaign entry point, TY = post-conversion, B = variant test). See [[reference_lp_clients]] for the full client list.
