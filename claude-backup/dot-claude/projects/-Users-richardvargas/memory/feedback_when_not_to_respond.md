Do not draft a response or flag for action when a todo is blocked waiting on someone else and Richard is not the bottleneck.

**Why:** Richard's silence is intentional in these cases — commenting would add noise without value. The ball is already in someone else's court.

**How to apply:** Before drafting a response, check if the last comment indicates someone else needs to act first (e.g., waiting on Nate for access, waiting on client feedback, waiting on a vendor). If so, skip unless there's a clear reason Richard needs to follow up.
