Start with sub-category breakdowns, not top-level buckets.

**Why:** In the RJ Nodado analysis session, a high-level 4-category breakdown was rejected as too vague. The user pushed for more granularity, requiring a full redo with 12 categories and detailed sub-types (e.g., "Landing Pages" split into Design & Launch, Edit/Update, Duplicate, QA Review, Script Update, etc.).

**How to apply:** When analyzing a team member's Basecamp timeline or assignments, immediately go to the granular level — 10-15 specific sub-categories minimum. Use the task `target` field (not the event title) for accurate full names. Filter by date window up front if the user specifies one.
